# Uncertainty-Aware Surgical Tool Detection

YOLOv8m-based surgical instrument detector with confidence-based failure detection, trained and evaluated on the OpenCAS/EndoVis laparoscopic instrument dataset. The model outputs standard bounding-box detections; this repository evaluates whether its native confidence score can also serve as a usable signal of its own unreliability, without any change to the detector architecture.

Paper: *Uncertainty-Aware Surgical Tool Detection Using YOLOv8: A Confidence-Based Reliability Framework for Intraoperative AI* (P. Hema, Sakthi Swarrup J).

## Summary of results

Seed-13 checkpoint, 64-image validation split, confidence threshold τ = 0.365:

| Metric | Value |
|---|---|
| Pearson r (confidence vs. error) | −0.885 |
| Spearman ρ (rank correlation) | −1.000 (p < 0.0001) |
| ROC-AUC (failure detection) | 1.000 |
| AUPR | 1.000 |
| Bootstrap 95% CI (AUC, 1000 resamples) | [1.000, 1.000] |
| Expected Calibration Error (ECE) | 0.0106 |
| Brier Score | 0.0117 |
| mAP@50 / mAP@50-95 | 0.3964 / 0.2585 |

Monte Carlo Dropout was tested and found architecturally inapplicable to YOLOv8, since the network uses Batch Normalisation exclusively and contains no dropout layers. Full methodology, the seven-condition perturbation analysis, and failure-case breakdown are in the paper.

## Dataset

OpenCAS/EndoVis laparoscopic instrument dataset — 160 annotated frames across four operative sequences (OP1–OP4, 40 images each), with per-instrument binary segmentation masks. Derived from the EndoVis Robotic Instrument Segmentation Challenge (Allan et al., 2019, arXiv:1902.06426).

The dataset is not redistributed in this repository. To reproduce the preprocessing and training steps, obtain the dataset separately and point the notebook at your local copy (see below).

## Reproducing the results

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
2. Open `uncertainty_aware_surgical_tool_detection.ipynb`. Near the top, the `CANDIDATES` list holds a set of candidate local paths to the dataset's `Training` directory — replace these with the path to your own copy of OpenCAS/EndoVis.
3. Run the notebook top to bottom. Training five seeds end-to-end on an A100 takes several hours; to skip straight to evaluation, load `best.pt` directly (the notebook already does this in the inference/evaluation cells) rather than retraining.
4. Evaluation, calibration, the seven-condition perturbation sweep, and all figures in `figures/` are regenerated from the loaded checkpoint.

Training used seed 13, label smoothing λ = 0.1, 150 epochs, AdamW with lr₀ = 0.005 on a cosine decay schedule, batch size 32, image size 640×640. Full hyperparameters and the augmentation pipeline are listed in the notebook and in the paper's Methods section.

## Pretrained weights

`best.pt` is the YOLOv8m checkpoint from seed 13 — the one used for every result reported in the paper. Load it directly with Ultralytics:

```python
from ultralytics import YOLO
model = YOLO("best.pt")
results = model.predict("path/to/image.png", conf=0.365)
```

A confidence threshold of 0.365 was selected by ROC sweep on the validation set; predictions below this are treated as abstentions (flagged for human review) rather than accepted detections.
